# Programação Orientada a Objetos I (POO I) — C#

Repositório destinado ao armazenamento e organização das soluções de atividades e exercícios conceitos e projetos desenvolvidos na disciplina de **POO I** curso de Análise e Desenvolvimento de Sistemas (ADS).

A ideia é organizar minhas soluções de forma fácil, e tentar aprender um poquinho de git/github fazendo isso.
Gemini me orientou a criar o repositório desse jeito.

## Conteúdos Abordados
- Classes, Atributos e Métodos
- Encapsulamento, Abstração e Construtores
- Exercícios práticos e modelagem de domínio

## Tecnologias
- Linguagem: C# 
- IDE: Visual Studio Code
